# Igris

Igris is a small standalone Python arena game inspired by a dark monarch fantasy style. You play as Igris, holding the throne room against waves of enemies before facing the Crownless Monarch.

## Requirements

- Python 3
- Tkinter, which is included with most normal Python installs

No extra packages are needed.

## How To Run

Open PowerShell in this folder and run one of these:

```powershell
python .\igris.py
```

or:

```powershell
py .\igris.py
```

If Python is not installed on your PC, this Codex workspace also has a bundled Python that can run the game:

```powershell
& "C:\Users\aryan kushwaha\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" "C:\Users\aryan kushwaha\OneDrive\Desktop\igris\igris.py"
```

## Controls

- Move: `WASD` or arrow keys
- Strike: `Space`
- Dash: `Shift`
- Royal Call: `E`
- Pause: `P`
- Restart after victory or defeat: `R`

## Goal

Clear each wave, stay alive, and defeat the Crownless Monarch in wave 6. Your score increases when you damage and defeat enemies.

## Tips

- Dash gives you a short moment of invulnerability.
- Royal Call is strongest when several enemies are close together.
- Archers are easier to beat if you keep moving.
- Save your dash for the boss charge or projectile bursts.
